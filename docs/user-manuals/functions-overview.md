# Functions overview

This guide lists the autoloaded shell functions in `.config/zsh/functions/`.
They are available after the Zsh framework starts. They do not need manual
registration.

## Daily commands

| Function | Purpose |
| --- | --- |
| `zsh-doctor` | Report loaded modules, compiled files, PATH issues, function load state, completion state, and framework health. |
| `node-doctor` | Report `mise`, Node, npm, pnpm, package-manager paths, project runtime pins, and duplicate Node candidates. It does not change state. |
| `restart-zsh` | Replace the current shell with a fresh Zsh process. |
| `zsh-profile` | Restart Zsh with startup profiling enabled. |

## Zsh maintenance

| Function | Purpose |
| --- | --- |
| `zsh-recompile` | Remove adjacent `.zwc` files under the Zsh config root and restart Zsh so modules compile again. |
| `zsh-rebuild-completions` | Remove and rebuild the Zsh completion dump and compiled completion cache. |

## Colima and Docker

| Function | Purpose |
| --- | --- |
| `colima-start` | Run `colima start` and pass through all arguments. |
| `colima-status` | Run `colima status` and pass through all arguments. |
| `colima-stop` | Run `colima stop` and pass through all arguments. |

See [Colima and Docker](colima-docker.md) for host/container boundaries and
common checks.

## Local AI wrappers

| Function | Purpose |
| --- | --- |
| `codex-local` | Run `codex` with AI secrets loaded through the Keychain wrapper. |
| `claude-local` | Run `claude` with AI secrets loaded through the Keychain wrapper. |
| `goose-local` | Run `goose` with AI secrets loaded through the Keychain wrapper. |
| `headroom-codex` | Start the Headroom launch agent if possible, then run `codex` with AI secrets. |
| `headroom-claude` | Load AI secrets and run `claude` through the Headroom proxy URL. |
| `headroom-doctor` | Run `headroom doctor` against `HEADROOM_PORT`, or port `8787` by default. |
| `prompthub-keys` | Run PromptHub key management from the PromptHub app virtual environment. |

## Common pitfalls

- Do not edit adjacent `.zwc` files. They are generated bytecode.
- Do not put large command bodies in app modules. Add a function file under
  `.config/zsh/functions/` instead.
- Do not assume a repository edit changes the active shell. The active tree is
  copy-installed at `~/.config/zsh/`.
- Do not store secrets in these function files. Use the Keychain helpers.
